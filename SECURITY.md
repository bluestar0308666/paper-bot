# Security policy

PaperBot stores API keys, user accounts, article summaries and usage data. Keep `config.json`, database files, logs and backups outside Git.

Use HTTPS, set a strong access password, and run PaperBot behind a reverse proxy or firewall. Do not expose the Node service directly when registration or administrative endpoints are enabled.

Report vulnerabilities through a private repository security advisory. Never attach real API keys, passwords, database files or user content to a public issue.
